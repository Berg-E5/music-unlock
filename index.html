      音乐平台为什么加密？

      不是音质问题，是生态绑定问题

      加密方式
      AES / 异或 / 私钥
      音频本体
      MP3 / FLAC 没变
      元数据
      歌名 / 歌手 / 封面
      解锁方式
      去除加密外壳

      网易云、QQ 音乐、酷狗、酷我这些平台下载下来的歌曲，都不是普通的 MP3/FLAC 文件，而是各自私有的加密容器：NCM、QMC、KGM、VPR …… 它们的共同点是：

      • 把原本的 MP3/FLAC 音频流用密钥加密后存储，文件头加一段魔数（如 NCM 的 CTENFDAM）；
      • 把歌名、歌手、专辑、封面、歌词等元数据也加密藏在容器里；
      • 只能在自家 App 客户端里播放，导入其他播放器、车机、剪辑软件全部失效。

      平台这么做的目的很简单：版权保护 + 生态锁定——让你没法轻易把下载的歌曲带到别处去。本工具做的事情是反向的：把加密外壳去掉，还原出原本的音频文件。音频数据本身没有改动，320kbps 出来还是 320kbps，FLAC 出来还是无损 FLAC。

      加密格式 vs 通用格式

      转换不改变音质，改变的是文件的通用性

      对比项 加密格式（NCM/QMC/KGM/VPR） 通用格式（MP3 / FLAC）
      是否加密 是，平台私钥封装 否，国际开放标准
      谁家播放器能放 仅原平台客户端 几乎所有播放器
      车载 U 盘 / MP3 播放器 无法识别 普遍支持
      手机自带播放器 无法播放 直接播放
      视频剪辑软件 剪映/PR 导入失败 可作为配乐
      元数据 加密藏在容器内 标准 ID3 / Vorbis，通用可读
      长期可用性 会员到期、歌曲下架都可能失效 不依赖任何账号
      音质 取决于容器内的音频流 转换后与原文件一致

      一句话：转换不会改变音乐本身，只让它不再受平台账号限制。

      关于无损保真

      本工具做的事情是去除加密外壳，不涉及任何重新编码。源文件是无损 FLAC 就输出 FLAC，是 320kbps MP3 就输出同样的 320kbps MP3。音质与原文件完全一致，你也不需要做任何格式设置。

      如果你想要 ALAC（苹果无损）或 Opus 等其他格式，正确做法也是先在这里还原出原始的 FLAC / MP3，再做无损转码——加密容器内部并不存在这些格式的音频流。

      转换会损失音质吗？

      不会。本工具只做"去除加密外壳"，原始音频数据完整保留，不重新编码。如果原文件是 320kbps 的 MP3，转换后仍然是 320kbps；如果原文件是无损 FLAC，转换后也是无损 FLAC。音质与原文件完全一致。

      转换后的文件保存在哪里？

      这取决于你浏览器的默认下载设置：

      • Windows / Mac 电脑：通常在系统的"下载"或 Downloads 文件夹中。
      • Android 手机：通常在"文件管理" → "内部存储" → Download 文件夹。
      • iPhone / iPad (iOS)：在"文件"App → "iCloud 云盘"或"我的 iPhone" → "下载"文件夹中。
      我的文件安全吗？会被上传吗？

      100% 安全。本工具采用纯客户端（Client-side）技术，所有文件转换均在你的浏览器本地完成。你的音乐文件绝不会上传到任何服务器，我们也不会保存、读取或收集你的任何文件内容。你可以在断网状态下使用本工具来验证这一点。

      为什么点击"添加文件"没有反应？

      请确保你使用的是现代浏览器（Chrome、Edge、Safari、Firefox）。如果在手机端使用，请检查是否授予了浏览器"访问文件"的权限。部分安卓浏览器可能需要长按上传按钮才能唤起文件选择器。

      下载的文件名为什么变了？

      为了保护隐私，部分浏览器在传递文件时会隐藏原始文件名。我们会尽力从加密容器内部的元数据中提取歌名和歌手来重命名文件，确保你能清楚地识别每一首歌。

      转换有文件大小或数量限制吗？

      没有限制。转换在你的浏览器本地完成，文件不经过网络传输，因此不存在服务器带宽或存储上限，几百 MB 的无损文件也能正常处理。需要上传文件的在线工具通常把单文件限制在 50MB 左右，无损音频很容易超标。数量同样不限，批量拖入即可。

      QQ 音乐的 .mgg / .mflac 为什么不能直接解？

      因为它们的密钥不在文件里。老格式（.qmc0 / .qmcflac 等）密钥直接写在文件头，浏览器拿到就能解；而 .mgg / .mflac 每首歌的密钥由 QQ 服务器单独下发，不存在任何公开的获取入口。

      所以这类文件只能借用你自己的 QQ 音乐客户端来解密：

      1. 下载 借壳解密工具，解压到本地
      2. 在这台电脑（已登录 QQ 音乐）上运行 run.bat 或 watch.bat
      3. 得到 .ogg / .mp3 后，拖回本页面上方的「已解密文件」区转格式

      整个过程在你自己的电脑上完成，文件不会上传到任何服务器。

      把下载的加密文件转出来合法吗？

      将自己付费获得的歌曲转换格式、仅在个人设备上播放，通常属于合理使用的范畴。但请不要公开传播、出售转换后的文件或将其用于商业用途，否则可能侵犯版权方的权利。各地法规存在差异，请在当地法律允许的范围内使用本工具。
